# 04 真实项目测试方案

> 状态：待评审。文中的指标阈值为建议值，请贵司确认或调整。

## 1. 原则

- 每个专业用本专业的真实项目验证，不以房建项目的结果代表其他专业；
- 用**贵司造价人员已完成的真实投标报价**作为对照基准，而不是由系统自己判断自己是否正确；
- 测试结果写入 `profession_test_cases`，直接驱动能力中心的状态。没有通过样本的专业不会显示"通过真实项目验证"。

## 2. 样本要求

每个样本项目需要：

| 材料 | 用途 |
| --- | --- |
| 招标文件全文（含补遗、答疑） | 识别计价要求、不可竞争费用规定 |
| 招标工程量清单（原始电子版和 PDF 版，如都有） | 清单识别与保护测试 |
| 招标人提供的报价模板或电子清单文件 | 导出测试 |
| 贵司当时的投标报价成果：计价表、综合单价分析表、人材机表、汇总表，最好有计价软件工程文件 | 对照基准 |
| 当时采用的定额版本、费率、价格基准期说明 | 复现计价上下文 |

数量建议：

- A 族各专业（房建、装饰、安装、市政、园林、钢结构）：每专业不少于 3 个项目，其中至少 1 个有补遗文件，至少 1 个为 PDF 或扫描版清单；
- 其他专业：每专业不少于 1 个项目可进入"自动组价需人工复核"，不少于 3 个可进入"通过真实项目验证"；
- 至少 2 个多专业综合项目（例如房建 + 安装 + 室外市政），验证多单位工程互不混用。

样本含商业信息，测试环境与生产环境隔离，样本不进入代码仓库，按贵司要求脱敏。

## 3. 测试层次

### 3.1 所有专业都要通过的基础测试（不依赖定额数据）

| 编号 | 测试 | 通过标准 |
| --- | --- | --- |
| T1 | 建立专业项目和单位工程 | 16 个专业均成功 |
| T2 | 上传并识别招标文件 | 项目所在地、专业、计价要求的抽取结果附出处，人工核对无误 |
| T3 | 清单识别 | 与原件逐项逐字段比对，电子版清单一致率 100%；PDF 或扫描版的差异全部进入异常提示，无静默错误 |
| T4 | 清单保护 | 通过界面、接口、直接 SQL（应用账号）尝试修改或删除原始清单，全部被拒绝并留有审计记录 |
| T5 | 补遗处理 | 导入补遗后生成新版本，差异报告正确，旧版本保留，受影响组价标记待复核 |
| T6 | 人工组价与计算 | 人工录入子目和资源后，引擎结果与手工验算一致 |
| T7 | 不可竞争费用锁定 | 通过界面、接口、批量调价、下浮、改基数构成等方式尝试改变锁定费用，全部被拒绝；合法调价后锁定费用按公式重算且轨迹完整 |
| T8 | 修改记录与版本 | 撤销、恢复正确；版本对比正确；审计记录完整 |
| T9 | 导出一致性 | 导出文件的清单字段与有效清单版本逐项一致；人为制造不一致时导出被阻止 |
| T10 | 数据隔离 | 尝试在单位工程中引用其他专业、其他版本的定额，被数据库拒绝；无数据专业执行自动匹配时提示数据缺口，不返回其他专业定额 |

### 3.2 有计价依据数据的专业

| 编号 | 测试 | 指标（建议值） |
| --- | --- | --- |
| T11 | 计价引擎对照 | 输入与对照报价相同的定额、消耗量、价格、费率时：综合单价、合价、各项费用、总价与对照报价**逐项一致**（按招标文件规定的精度）。任何差异都要定位原因并归类：系统错误、规则数据错误、对照报价本身的问题 |
| T12 | 定额匹配 | 与对照报价的定额选择比较：首选一致率不低于 70%，前三候选包含率不低于 90%；高置信度结果的错误率不超过 5%。不一致项由造价人员判定是系统错误还是合理的不同选择 |
| T13 | 漏套、重复计价检查 | 在样本中人为植入错误，检出率不低于 90% |
| T14 | 资源价格匹配 | 规格或单位不同的资源无一被错误匹配；价格覆盖率如实显示 |
| T15 | 自动组价端到端 | 全自动结果与对照报价的总价偏差、逐项偏差分布形成报告；需人工处理的清单项比例形成报告。此项只报告、不设硬阈值，由贵司判断是否达到可用 |
| T16 | 模板导出 | 用招标人原始模板导出，能被贵司现用流程（及招标平台，如可测试）正常接收 |

关于 T12：定额选择在实务中并非唯一答案，同一清单项不同造价人员可能合理地选用不同子目。因此指标以人工判定后的结果为准，原始一致率和判定后正确率都记录。

## 4. 各专业的专项测试点

| 专业 | 需要特别覆盖的内容 |
| --- | --- |
| 房建 | 混凝土、钢筋、模板、脚手架等措施与实体的划分；装饰多层做法的一对多组合 |
| 市政 | 道路结构层组合；管网土方与管道的重复计价检查 |
| 安装 | 主材与辅材划分；未计价材料；系统调试费、超高增加费等按系数计取的费用 |
| 钢结构 | 制作、运输、安装、防腐、防火的组合；按吨计量的换算 |
| 园林 | 苗木规格匹配；养护期费用 |
| 公路 | 编制办法的费率体系；清单细目与定额的对应 |
| 水利 | 部颁与省颁依据的选择；清单计价规范的特殊要求 |
| 电力、石化、铁路、矿山、水运、民航 | 各自的费用构成和取费程序；专业设备与材料的划分 |
| 幕墙及特种、环保 | 跨定额册的组合；补充定额的管理 |

## 5. 回归与持续验证

- 所有通过的样本固化为回归用例，每次引擎、适配器、规则数据更新后自动重跑 T11；
- 规则数据或定额版本更新后，受影响专业的验证状态自动降级为"需重新验证"，重跑通过后恢复。

## 6. 与第十七章验收标准的对应

| 验收条 | 测试 |
| --- | --- |
| 1 独立分类和适配器 | T1 + 适配器接口自检 |
| 2 可建立项目 | T1 |
| 3 上传并识别招标文件 | T2 |
| 4 导入和保护原始清单 | T3、T4、T5 |
| 5 人工组价及计算 | T6 |
| 6 定额和资源独立管理 | T10 + 数据中心导入校验流程演示 |

| 9 清单一致性检查 | T9 |

| 11 修改记录及计算版本 | T8 |
| 12 成果导出机制 | T9、T16 |

验收时按专业出具结论表：每个专业列出通过的测试、使用的样本、当前能力状态、遗留缺口。不出具"全专业已完成"的笼统结论。
